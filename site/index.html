The done rule

Neither agent closes a goal alone.

The agent that wrote the code is the worst judge of it. tandem ends a run only when the other agent has looked and found nothing to fix.

  • Both say done, back to backOne agent's done, then the other's on the very next turn.
  • The second turn changes nothingA fresh look that produces no commit. If it fixes something, the count starts over.
  • Your check passesTests, a linter, a build: any command you give with --check or in the goal file.
In the terminal

Keep typing while they work.

Each turn arrives as a card. Type a message and the next agent reads it; /now stops the turn and hands it your correction. /board shows what the agents agree on, what is open, models and cost.

Why two CLIs

Two peers, not an agent with a tool.

Plugins and skills already let Claude Code call Codex, or run Claude inside Codex. That keeps one agent in charge, judging its own work. tandem gives both the same job and puts the referee outside them.

One agent calls the other

  • The driver decides when to ask for a second opinion, and whether to listen.
  • The driver says when the work is finished.
  • Edits land in your checkout; you commit.
  • When the driver's account hits its limit, everything stops.

tandem

  • Every turn is reviewed by the other agent, by design.
  • Only both agents plus your check can end a run.
  • Own worktree and branch, one commit per turn. Your checkout is never touched.
  • One agent hits its limit, the other carries on alone, and the work gets reviewed later.

Resume anything

All state is on disk. After a crash, a closed laptop or Ctrl+C twice, tandem resume continues the run.

Scripts and CI

tandem -p "goal" --output-format json. Exit codes say how it ended: 0 done, 2 out of turns, 3 blocked, 6 over budget.

A cost cap

--max-cost 5 stops before a turn that would start past five dollars of reported spend.

Campaigns

Chain goals on one branch. An agent picks the next one from your project's own plan.

Models per agent

Tab on an empty line changes model and effort from the next turn. /models saves your defaults.

Notifications

A desktop notification when a run ends or both agents are waiting for their limits.

Install

Three steps to a first run.

You need Python 3.9+, Node 18+, Git, and both agent CLIs logged in with your own accounts.

Install the agents, if you do not have them

npm install -g @anthropic-ai/claude-code @openai/codex
claude auth login && codex login

Install tandem and check the setup

npm install -g @lyczos/tandem
tandem doctor            # every line should say ok

Start it in any git repository with a commit

cd ~/code/my-project
tandem

Know what it runs. Claude Code works from an allow-list of commands. That is a guard rail, not a sandbox: python3 or npm can run any code as your user. Only Codex is sandboxed. Use tandem on repositories you trust, ideally in a VM or container if the code is not yours.
